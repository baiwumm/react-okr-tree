# react-okr-tree

基于 React 的组织架构树 / OKR 树组件，[vue3-okr-tree](https://github.com/baiwumm/vue3-okr-tree) 的 React 完整复刻版，支持类似飞书 OKR 的**根节点左右双向展开**布局。

- npm 包：[react-okr-tree](https://www.npmjs.com/package/react-okr-tree)（源码与完整文档在 [`packages/react-okr-tree`](./packages/react-okr-tree)）
- 在线文档站：<https://react-okr-tree.baiwumm.com>
- 版本号自 1.13.0 起与 `vue3-okr-tree` 锁步发布：两边同号即同一功能面
